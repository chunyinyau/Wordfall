# Wordfall

A "falling words" typing game. Open `index.html` in a browser to run Wordfall.

Files:

- [index.html](index.html)
- [style.css](style.css)
- [game.js](game.js)

How to run:

1. Open the folder in your code editor.
2. Serve the folder with a local static server, then open `index.html` in the browser.
